# Dashboard_de_Vendas_do_Xbox_com_Excel

## 📌 Visão Geral
<p align="justify">
Este projeto consiste no desenvolvimento de um **dashboard analítico** com foco em **apoio à tomada de decisão estratégica**, a partir de dados de assinaturas e uso de cupons promocionais.  
O objetivo principal é transformar dados transacionais em **informações claras, contextualizadas e acionáveis**, permitindo que gestores compreendam não apenas os resultados, mas também os comportamentos e padrões por trás deles.  
</p>

## 🎯 Objetivo do Projeto
- Analisar o desempenho do plano de assinatura  Ultimate
- Entender o impacto financeiro e comportamental dos cupons promocionais  
- Apoiar decisões comerciais com base em dados estruturados

## 🧠 Abordagem Analítica

Antes de pensar em gráficos, cores ou layout, o foco esteve em compreender profundamente a base de dados.

O maior desafio do projeto foi **entender a base**:
- Dados não falam sozinhos  
- Campos técnicos, nomenclaturas confusas e relações não evidentes exigiram análise cuidadosa  
- Foi necessário entender como cada variável se conectava às demais e quais perguntas de negócio poderiam ser respondidas de forma confiável  

A partir dessa compreensão, foi desenvolvido um **pensamento lógico e analítico estruturado**, guiado pelas seguintes perguntas:
1. Qual é o objetivo do dashboard?
2. Quais perguntas de negócio precisam ser respondidas?
3. Quais dados sustentam essas respostas?
4. Como apresentar essas informações de forma simples e direta?

---

## 📊 Estrutura do Dashboard (Storytelling)

O dashboard foi organizado para conduzir o olhar do gestor de forma natural e intuitiva:

### 1️⃣ Visão Geral
- Indicadores principais (Big Numbers)  
- Contexto temporal da análise  

### 2️⃣ Análise da Assinatura
- Faturamento  
- Modalidades de pagamento  
- Comportamentos recorrentes 

### 3️⃣ Análise de Cupons
- Cupons mais utilizados  
- Impacto financeiro dos cupons nas assinaturas

## 🚀 Habilidades Desenvolvidas

- **Análise de Dados:** Interpretação de bases complexas e entendimento das relações entre variáveis.
- **Pensamento Analítico e Lógico:** Construção de métricas alinhadas às perguntas de negócio.
- **Visualização de Dados:** Criação de dashboards claros, simples e orientados à tomada de decisão.
- **Storytelling com Dados:** Organização das informações para guiar a leitura do gestor.
- **Análise de Negócio:** Tradução de necessidades estratégicas em indicadores relevantes.

---

## 📋 Como Usar

1. **Carregue a base de dados no dashboard.**
2. **Defina o período de análise** para contextualizar os indicadores.
3. **Analise os Big Numbers** para visão geral do negócio.
4. **Explore as análises de assinaturas e cupons** para identificar padrões e oportunidades.
5. **Utilize os insights** como apoio à tomada de decisão estratégica.

---

## ✅ Conclusão
O principal aprendizado deste projeto foi compreender que **um bom dashboard não é aquele que mostra muitos dados**, mas aquele que **responde as perguntas certas com clareza**.

O resultado final é um dashboard funcional, orientado à decisão, que conecta dados operacionais a **estratégias de crescimento e eficiência comercial**, reforçando o papel do analista de dados como ponte entre dados e negócio.
